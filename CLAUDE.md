# Working agreement

- Always get explicit confirmation from the user before editing or writing any
  code file in this repo (Edit/Write on source, config, or infra files).
  Research, reading files, running read-only commands (curl, browser
  exploration, docs lookups), and discussing a plan are fine without asking.
  Do not start implementing just because a plan was discussed — wait for an
  explicit "go ahead" / "implement this" / equivalent from the user first.
